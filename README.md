# ค้นไฟล์ + สรุปยอดเงินตาม PO — งานรั้ว พระราม 5

รวมขั้นตอน **ค้นหาไฟล์ (Everything) → จัดตาราง (Ctrl+T) → สรุปยอด (PivotTable)**
ให้เหลือคำสั่งเดียว รันออฟไลน์ 100% ไม่ต้องต่อเน็ต ไม่ต้องกดเครื่องคิดเลข

| ไฟล์ | หน้าที่ |
|---|---|
| `สรุปยอด_PO_รั้วพระราม5.py` | **ตัวหลักตัวเดียว** — มี 2 โหมด: `--mode po` (ตามเลขที่ PO) และ `--mode wbs` (ตาม WBS จาก SAP) |
| `วิเคราะห์_PO_รั้ว_4111.py` | ตัวเรียกต่อของเดิม เรียก `--mode wbs` ให้ — เก็บไว้ให้คำสั่งเก่ายังใช้ได้ |
| `รัน_สรุปยอด.bat` | ดับเบิลคลิกรันบน Windows ได้เลย ไม่ต้องพิมพ์คำสั่ง |
| `requirements.txt` | ไลบรารีที่ต้องติดตั้ง (มีตัวเดียวคือ openpyxl) |

## 2 โหมด ต่างกันยังไง

| | `--mode po` (ค่าเริ่มต้น) | `--mode wbs` |
|---|---|---|
| อ่านจาก | ไฟล์งานหลายไฟล์ (ค้นเจอเอง) | ไฟล์ SAP ME2N export ไฟล์เดียว |
| จัดกลุ่มตาม | **เลขที่ PO** | **WBS Element** (FH-001, FN-001…) |
| คำนวณ | ยอดรับ − ยอดจ่าย = ยอดสุทธิ | ปริมาณ × ราคา/หน่วย |
| ได้ไฟล์ | Excel 4 ชีต | ข้อความ `.txt` |
| ใช้ตอน | ตามเก็บเงินตามใบ PO | ดูภาพรวมงบตามหมวดงานรั้ว |

## 1. คำสั่งค้นหาใน Everything (ใช้มือก็ได้)

คัดลอกไปวางในช่องค้นหาของ Everything ได้เลย — ระบบจะกรองเฉพาะไฟล์ Excel
ที่ **แก้ไข** ในช่วง มิ.ย. 66 – ก.พ. 67 ให้อัตโนมัติ

```
รั้ว พระราม 5 ext:xlsx dm:2023-06-01..2024-02-29
```

| ส่วนของคำสั่ง | แปลว่า |
|---|---|
| `รั้ว พระราม 5` | ชื่อไฟล์ต้องมีครบทั้ง 3 คำ (เว้นวรรค = และ/AND ไม่ใช่วลีต่อกัน) |
| `ext:xlsx` | เฉพาะไฟล์ Excel (ใส่หลายนามสกุลได้ เช่น `ext:xlsx;xlsm`) |
| `dm:2023-06-01..2024-02-29` | วันที่ **แก้ไขไฟล์** (date modified) ตั้งแต่ 1 มิ.ย. 66 ถึง 29 ก.พ. 67 |

> ถ้าอยากให้คำค้นไปจับกับ *ทั้งพาธ* ไม่ใช่แค่ชื่อไฟล์ ให้เปิด
> **ค้นหา (Search) → จับคู่พาธ (Match Path)** ใน Everything

### เทคนิค: ตั้งคีย์ลัดเรียก Everything

**เครื่องมือ (Tools) → ตัวเลือก (Options) → แป้นพิมพ์ (Keyboard) →
"แสดงหน้าต่างค้นหา" (Show search window)** แล้วกด `Alt + Spacebar`

หน้างานวุ่น ๆ กดปุ่มเดียวก็พิมพ์หาไฟล์ต่อได้เลย

## 2. สรุปยอดอัตโนมัติ (แทนขั้นตอน PivotTable)

### ติดตั้งครั้งเดียว

```bat
pip install -r requirements.txt
```

### รัน

```bat
:: ใช้คำค้นและช่วงวันที่มาตรฐาน (รั้ว พระราม 5 / มิ.ย.66–ก.พ.67)
python สรุปยอด_PO_รั้วพระราม5.py

:: ดูก่อนว่าจะหยิบไฟล์ไหนมาบ้าง ยังไม่คำนวณ
python สรุปยอด_PO_รั้วพระราม5.py --dry-run

:: ไม่มี es.exe ก็ได้ ระบุโฟลเดอร์ให้สแกนเองแทน (ใส่ --root ซ้ำได้หลายอัน)
python สรุปยอด_PO_รั้วพระราม5.py --no-es --root "D:\งานรั้ว" --root "E:\OneDrive"

:: เปลี่ยนงาน/เปลี่ยนช่วงเวลา
python สรุปยอด_PO_รั้วพระราม5.py --keyword "รั้ว ราชพฤกษ์" --since 2024-01-01 --until 2024-12-31

:: โหมด WBS - สรุปยอดตาม WBS Element จากไฟล์ SAP ME2N export
python สรุปยอด_PO_รั้วพระราม5.py --mode wbs --source "C:\...\4111_po.xlsx"

:: โหมด WBS - ไฟล์คนละหน้าตา ระบุชีต/แถวหัวตารางเอง
python สรุปยอด_PO_รั้วพระราม5.py --mode wbs --source "งบ.xlsx" --sheet "Sheet1" --header-row 1
```

หรือ **ดับเบิลคลิก `รัน_สรุปยอด.bat`** ถ้าไม่อยากพิมพ์คำสั่ง

### ตัวเลือกทั้งหมด

| ตัวเลือก | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| `--keyword` | `รั้ว พระราม 5` | คำค้น เว้นวรรค = ต้องมีครบทุกคำ |
| `--since` / `--until` | `2023-06-01` / `2024-02-29` | ช่วงวันที่แก้ไขไฟล์ (YYYY-MM-DD) |
| `--root` | โฟลเดอร์ผู้ใช้ | โฟลเดอร์ที่จะสแกน ใส่ซ้ำได้ (ใช้ตอนไม่มี es.exe) |
| `--out` | `สรุปยอด_PO_<วันเวลา>.xlsx` | ที่อยู่ไฟล์สรุปที่จะเขียนออก |
| `--es` | หาให้เอง | ระบุที่อยู่ `es.exe` เอง |
| `--no-es` | ปิดอยู่ | ไม่ใช้ Everything ให้สแกนโฟลเดอร์เองเลย |
| `--match-path` | ปิดอยู่ | ให้คำค้นเทียบกับพาธเต็ม ไม่ใช่แค่ชื่อไฟล์ |
| `--dry-run` | ปิดอยู่ | แสดงรายชื่อไฟล์ที่เจอเฉย ๆ ยังไม่อ่าน |
| `--top` | `0` (ทั้งหมด) | จำกัดจำนวน PO ที่พิมพ์บนจอ |
| `--mode` | `po` | `po` = สรุปตามเลขที่ PO · `wbs` = สรุปตาม WBS Element |

### ตัวเลือกที่ใช้เฉพาะ `--mode wbs`

| ตัวเลือก | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| `--source` | *(จำเป็น)* | ไฟล์ SAP ME2N export เช่น `4111_po.xlsx` |
| `--sheet` | `4111_po` | ชื่อชีตในไฟล์ SAP (ถ้าใส่ผิดจะบอกว่ามีชีตอะไรให้เลือกบ้าง) |
| `--header-row` | `4` | แถวที่เป็นหัวตาราง (ข้อมูลเริ่มแถวถัดไป) |
| `--out` | `สรุป_PO_WBS_<วันเวลา>.txt` | ที่อยู่ไฟล์รายงาน |

## 3. ได้อะไรออกมา

**บนหน้าจอ** — ตาราง 4 คอลัมน์ อ่านบนมือถือได้

```
+-------------+--------------+--------------+--------------+
| เลขที่ PO   | ยอดรับ       | ยอดจ่าย      | ยอดสุทธิ     |
+-------------+--------------+--------------+--------------+
| PO-6606-001 |   400,000.00 |   225,000.00 |   175,000.00 |
| PO-6607-002 | 2,080,000.50 | 1,150,000.00 |   930,000.50 |
+-------------+--------------+--------------+--------------+
| รวมทั้งสิ้น | 2,480,000.50 | 1,375,000.00 | 1,105,000.50 |
+-------------+--------------+--------------+--------------+
```

**ไฟล์ Excel สรุป** `สรุปยอด_PO_<วันเวลา>.xlsx` มี 4 ชีต

| ชีต | มีอะไร |
|---|---|
| สรุปตาม PO | เลขที่ PO / ยอดรับ / ยอดจ่าย / **ยอดสุทธิ** / จำนวนรายการ / จำนวนไฟล์ + แถวรวมทั้งสิ้น (เป็นสูตร SUM จริง) |
| รายละเอียด | ทุกแถวที่ดึงมา พร้อมชื่อไฟล์–ชีต–เลขแถว ไว้ไล่ตรวจย้อนกลับได้ว่าตัวเลขมาจากไหน |
| ไฟล์ที่อ่าน | ไฟล์ทั้งหมดที่เจอ + สถานะ (ไฟล์ไหนอ่านไม่ได้ เพราะอะไร) |
| ข้อมูลการรัน | รันเมื่อไหร่ ด้วยคำค้น/ช่วงวันที่อะไร ยอดรวมเท่าไหร่ |

พร้อมไฟล์ `.log` ชื่อเดียวกัน บันทึกว่าทำอะไรไปบ้าง

### โหมด `--mode wbs` ได้อะไร

ไฟล์ `.txt` 3 ส่วน

1. **รายละเอียดรายหมวด** — แต่ละ WBS มีรายการอะไรบ้าง เลขที่ PO / ปริมาณ / ราคา / มูลค่า / วันที่
2. **สรุปรวมทุกหมวด** — มูลค่าต่อหมวด + รวมทั้งสิ้น
3. **เฉพาะรั้วกั้นระหว่างแปลง** — ตัดตู้รับจดหมายและรายการที่ไม่ใช่ตัวรั้วออก แล้วรวมตาม PO

หมวด WBS ที่รู้จัก

| WBS | คืองานอะไร |
|---|---|
| FH-001 | รั้วแบ่งแปลง / รั้วบ้าน (รายแปลง) |
| FN-001 | รั้วโครงการ เหนือดิน H 3.0 ม. |
| FN-002 | รั้วชั่วคราว / รั้วกั้นโซนก่อสร้าง |
| FN-003 | รั้วเขื่อน Type P2, P3, P4 และ Type พิเศษ |
| FN-004 | งานวางหมุด ทาสีรั้ว รั้วโปร่งซุ้ม |
| FC-001 | ซุ้ม ป้อม ป้าย และประตูรั้วทางเข้าหลัก |

เพิ่ม/แก้หมวดได้ที่ลิสต์ `รหัส_WBS_งานรั้ว` ที่หัวสคริปต์

## 4. สคริปต์อ่านไฟล์ยังไง (เผื่อไฟล์งานหน้าตาไม่เหมือนกัน)

- **หาหัวตารางเอง** ใน 30 แถวแรก ไม่จำเป็นต้องอยู่แถวที่ 1 (มีโลโก้/ชื่อโครงการข้างบนได้)
- **ชื่อคอลัมน์ยืดหยุ่น** — `เลขที่ PO` / `PO` / `เลขที่ใบสั่งซื้อ`, `ยอดรับ` / `รายรับ`, `ยอดจ่าย` / `รายจ่าย` ฯลฯ
- **ไล่ทุกชีต** ในไฟล์ ชีตไหนไม่มีหัวตารางก็ข้ามไป
- **ช่อง PO ที่ merge หรือเว้นว่าง** จะลากค่าจากแถวบนลงมาให้
- **แถว "รวมทั้งสิ้น" ของแต่ละชีตถูกข้าม** ไม่งั้นยอดจะเบิ้ล
- **ตัวเลขแปลก ๆ อ่านได้หมด** — `1,234.50` / `(1,234)` = ติดลบ / `฿` / `บาท` / เลขไทย `๑๒๓` / `-` = 0
- **PO ตัวพิมพ์เล็ก-ใหญ่ต่างกันรวมเป็นใบเดียวกัน** (`po-6606-001` = `PO-6606-001`)
- **ยอดสุทธิ = ยอดรับ − ยอดจ่าย** ต่อ PO

## 5. เจอปัญหา ทำยังไง

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `ไม่พบไลบรารี openpyxl` | `pip install -r requirements.txt` |
| ไม่เจอไฟล์เลย | ลด `--keyword` ให้สั้นลง, ขยายช่วง `--since/--until`, หรือระบุ `--root` ให้ตรงโฟลเดอร์ |
| ขึ้น `ไม่พบหัวตาราง PO/ยอดรับ/ยอดจ่าย` | ชื่อคอลัมน์ในไฟล์นั้นเรียกอย่างอื่น — เพิ่มชื่อลงในลิสต์ `ชื่อคอลัมน์_*` ที่หัวสคริปต์ |
| ขึ้น `เจอสูตรแต่ไม่มีค่าที่เซฟไว้` | ไฟล์ถูกสร้างจากโปรแกรมอื่น ยังไม่มีค่าที่คำนวณแล้ว — เปิดใน Excel แล้วกดเซฟหนึ่งครั้ง |
| `เขียนไฟล์ไม่ได้` | ไฟล์สรุปเปิดค้างอยู่ใน Excel ปิดก่อนแล้วรันใหม่ |
| ไฟล์เป็น `.xls` (ของเก่า) | เปิดแล้ว **บันทึกเป็น (Save As) → .xlsx** ก่อน |
| โหมด wbs ขึ้น `ไม่พบชีตชื่อ ...` | ข้อความจะบอกว่าไฟล์นั้นมีชีตอะไรบ้าง เลือกมาใส่ `--sheet "ชื่อชีต"` |
| โหมด wbs ขึ้น `ไม่พบแถวข้อมูลเลย` | หัวตารางไม่ได้อยู่แถวที่ 4 — ระบุด้วย `--header-row` |

## 6. ถ้าอยากทำมือเหมือนเดิม (สำรองไว้)

1. ค้นไฟล์ใน Everything ด้วยคำสั่งข้อ 1 → ดับเบิลคลิกเปิดไฟล์
2. กด `Ctrl + T` แปลงข้อมูลเป็นตาราง (Table)
3. **แทรก (Insert) → ตารางสรุปข้อมูล (PivotTable)**
4. ลาก `เลขที่ PO` ลงช่อง **แถว (Rows)**
5. ลาก `ยอดรับ` และ `ยอดจ่าย` ลงช่อง **ค่า (Values)**
6. หายอดสุทธิ: **การวิเคราะห์ PivotTable (PivotTable Analyze) → เขตข้อมูล รายการ และชุด (Fields, Items & Sets) → เขตข้อมูลจากการคำนวณ (Calculated Field)** สูตร `= ยอดรับ - ยอดจ่าย`

ข้อเสียของวิธีมือ: ทำได้ทีละไฟล์ ถ้ามีหลายไฟล์ต้องรวมเองก่อน — สคริปต์ข้อ 2 ทำให้ทั้งหมดในรอบเดียว
